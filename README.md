# Hiba Ben Adou - Personal Portfolio Website

A premium, modern portfolio website built with React, Vite, Tailwind CSS, and Framer Motion.

## Features

- **Premium Dark Theme**: Elegant dark theme with purple, indigo, and turquoise accents
- **Dark/Light Mode Toggle**: Seamless theme switching
- **Smooth Animations**: Framer Motion animations throughout
- **Responsive Design**: Optimized for desktop, tablet, and mobile
- **Sections**: Hero, About, Skills, Projects, Education, Certifications, Download CV, Contact
- **CV Downloads**: Three specialized CVs (Data & AI, Cloud & DevOps, Software Engineering)

## Technologies

- React 18
- Vite
- Tailwind CSS 4
- Framer Motion
- Lucide React Icons

## Installation

```bash
npm install
```

## Development

```bash
npm run dev
```

## Build

```bash
npm run build
```

## Deployment

This project is designed for GitHub Pages deployment. The build output in the `dist` folder should be deployed to the `gh-pages` branch or the main branch with GitHub Pages configured.

## CV Files

Place your CV PDFs in the `public/assets/` directory:
- `cv-data-ai.pdf` - Data & AI focused CV
- `cv-cloud-devops.pdf` - Cloud & DevOps focused CV
- `cv-software-engineering.pdf` - Software Engineering focused CV
